# Machine Learning

Coursework and practical assignments completed for the **Machine Learning** course, covering concept learning, classification, model evaluation, and statistical comparison.

## Assignment 1 – Concept Learning

This assignment applies concept-learning techniques to **email spam classification** using the Spambase dataset. The data is preprocessed and discretized before applying **Least General Generalization (LGG)** and LGG conjunction rules.

The task explores how generalization rules can be learned from examples and then used for classification. The resulting predictions are evaluated to examine how effectively the learned concepts distinguish spam from non-spam examples.

## Assignment 2 – Classification Algorithm Comparison

This assignment compares **Naive Bayes, Decision Tree, and K-Nearest Neighbour (KNN)** classifiers on the Spambase dataset. The models are evaluated using **10-fold cross-validation**, with accuracy, F1-score, and training time used as performance measures.

In addition to predictive performance, the assignment applies the **Friedman test** and **Nemenyi post-hoc test** to investigate whether the differences between the classifiers are statistically significant.
